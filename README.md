# GW Police Job (RedM)

## 📜 Description (Tebex / YouTube)
Introducing the most advanced and powerful Police Job script for RedM. Crafted with the highest standards, this script provides an unprecedented interactive experience that elevates Roleplay servers and equips law enforcement with all the necessary tools to maintain security.

**Key Features:**
- 💻 **Bilingual MDT System (English/Arabic)**: Seamlessly manage citizens, criminal records, citations, fines, and warrants.
- 👮 **Smart Personnel Management**: Execute promotions and dismissals directly from the system, featuring an automated salary payout system based on ranks with a custom timer.
- 🔫 **Advanced Armory System**: Interactive NPC menu for purchasing weapons, ammunition, and tactical gear.
- 🐎 **Strategic Vehicles & Support**: Dispatch prison wagons, armored vehicles, and patrol units based on officer rank and authorization.
- 🚨 **Full Field Interaction**: Realistic handcuffing, searching, escorting, putting in/taking out of vehicles, multi-city jail systems (Valentine, Saint Denis, etc.), and a GPS-tracked Panic Button.
- ⚙️ **Fully Unlocked Config**: Customize every aspect of the script to perfectly match your server's unique needs.

## ⚙️ Configuration (Config.lua)
Through the `Config.lua` file, you can completely customize the script to easily suit your server. This includes changing languages, adjusting salaries, setting armory locations and available items for officers, and configuring the coordinates for jails and stations across the map.
